# Reviewer packs

Packs for external reviewers: a folder per pack with `README.md` (`templates/REVIEWER_PACK_README_TEMPLATE.md`), a findings extract, coverage matrix, evidence index, redaction confirmation and a static HTML entry page without external assets. Returned packs are untrusted input: each returned finding is assessed in a new run and only then registered. No pack exists yet. Packs of this public repository contain nothing beyond what the repository itself publishes.
